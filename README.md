# iShop - Интернет-магазин на Django

## Описание проекта
iShop - это полнофункциональный интернет-магазин, разработанный на Django с использованием современных веб-технологий. Проект включает в себя систему управления продуктами, категориями, пользователями и заказами.

## 🚀 Функциональность

### Основные возможности
- **Каталог товаров** с категориями (Электроника, Одежда, Дом и сад)
- **CRUD операции** для продуктов (создание, чтение, обновление, удаление)
- **Система пользователей** с аутентификацией
- **Управление заказами**
- **Блог** для публикации статей
- **Контактная информация**

### Безопасность и валидация
- Валидация запрещенных слов в названиях и описаниях продуктов
- Проверка цены на отрицательные значения
- Валидация загружаемых изображений (формат, размер)
- Защита от неавторизованного доступа к CRUD операциям

## 🛠 Технологический стек

### Backend
- **Django 4.2.7** - основной фреймворк
- **Python 3.13** - язык программирования
- **SQLite** - база данных (для разработки)

### Frontend
- **Bootstrap 5.3** - CSS фреймворк
- **HTML5/CSS3** - верстка
- **JavaScript** - клиентская логика

### Дополнительные компоненты
- **Django Forms** - обработка форм с валидацией
- **Class-Based Views** - для CRUD операций
- **Django Authentication** - система пользователей
- **ImageField** - работа с изображениями
